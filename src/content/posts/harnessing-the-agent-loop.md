Agent harness 是包裹在 LLM 外层的那层脚手架——它决定了模型是"能说话"还是"能做事"。

大多数讨论集中在模型能力上：参数量、上下文窗口、推理速度。但从产品视角看，harness 才是差异化的主战场。两个产品用同一个 GPT 模型，用户体验可以天差地别——差距不在模型，在 harness。

## 一个比喻

模型是发动机，harness 是底盘和操控系统。一辆车好不好开，发动机只是其中一个变量。方向盘的灵敏度、悬挂的调校、刹车的线性度——这些才是驾驶员每天感受到的东西。

AI 产品也一样。用户每天感受到的不是"模型参数有多少"，而是：回答是否准确？操作是否顺畅？AI 是否记住了上次的需求？错误时是否有合理的兜底？这些体验全部由 harness 决定。

## 为什么行业还在讨论模型

原因很简单：模型是"给定的"，harness 是"你的"。

模型能力由 OpenAI、Anthropic、Google 这些公司决定——你无法改变 GPT 的参数、无法调整 Claude 的推理策略。在模型层面，所有使用同一 API 的产品是完全同质的。竞争的终点是价格战，而不是体验差异。

但 harness 是产品团队自己的设计决策：工具怎么组织、记忆怎么管理、规划怎么深度、错误怎么兜底。这些决策积累起来，就形成了产品之间的实质性差异——用户能感知到的差异。

这也是为什么"套壳"产品注定失败。一个只是把 API 包装成聊天的产品，harness 层几乎为零——没有工具调度、没有记忆管理、没有任务规划。它和另一个同样零 harness 的产品之间，不存在任何让用户选择它的理由。

## Harness 的三层结构

一个完整的 agent harness 包含三个核心层：

**Tools（工具层）** —— 决定 agent 能"做什么"。

这不是简单的 function calling 列表。大多数产品的工具层还停留在"给模型一堆 API，然后祈祷它知道该调哪个"的阶段。但真正影响用户体验的是工具的组织方式：哪些工具应该优先暴露？工具之间的依赖关系怎么处理？调用失败时是否自动降级？返回结果的格式是否让模型能准确解析？

举个例子：一个订机票的 agent，如果工具层只是把航空公司 API 直接丢给模型，它大概率会在航班搜索、价格排序、预订确认之间反复纠缠——因为它不知道用户关心的是价格还是时间，不知道搜索结果要不要按价格排序，不知道预订之前是否需要先确认退改规则。

好的工具设计让 agent 像一个有经验的操作员，而不是一个拿着工具箱但不知道先拿什么的实习生。操作员不需要知道每把螺丝刀的型号，他只需要知道"拧这个螺丝用十字头"，而工具层就是帮他做这个匹配。

**Memory（记忆层）** —— 决定 agent 能"记住什么"。

短期记忆是当前对话的上下文窗口管理——这层的基本挑战是容量：128K token 看起来很大，但长对话 + 多工具调用 + 附加参考文档会很快填满。产品经理需要决定：当窗口快满的时候，丢弃什么？保留什么？是否主动压缩已经处理过的对话？

长期记忆是跨会话的知识持久化——今天的对话、明天的对话、上个月的对话，哪些信息需要沉淀？沉淀之后怎么索引？用户下次来的时候怎么召回？

关键不是"存更多"，而是"忘得对"——知道什么该记住、什么该丢弃、什么时候该召回。这会在后面的文章里深入拆解。

**Planning（规划层）** —— 决定 agent 能"想多远"。

最简单的规划层：用户说什么，agent 直接做。这是大多数聊天产品的现状——没有规划，只有执行。

稍深一层：agent 先拆解用户的意图，确认关键信息，然后制定步骤。比如用户说"帮我订下周去东京的机票"，agent 不直接搜索，而是先确认：下周具体哪几天？东京哪个机场？预算上限？是否需要酒店？

再深一层：agent 不仅规划自己的执行路径，还会评估可行性、预判风险、准备兜底方案。"搜索了一圈发现你要的日期没有直飞航班，但有一条转机路线价格便宜一半——要不要看？"

规划层的深度决定了 agent 是"工具执行者"还是"问题解决者"。前者只能回答用户问的问题，后者能解决用户真正想解决的问题——这两个问题往往不是同一个。

## 一个现实观察

过去一年，AI 行业的一个明显趋势是：模型能力在趋同，harness 能力在分化。

GPT-4o、Claude 3.5、Gemini 1.5 Pro——在纯推理能力上，它们之间的差距已经不大到足以影响大多数产品的用户体验。但在工具调用的一致性、长对话的稳定性、多步骤任务的完成率上，差异仍然明显——而这些差异几乎完全来自 harness 层。

所以，如果你是一个 AI 产品经理，你应该把主要精力放在哪里？不是追逐最新的模型版本号，而是设计好你的 harness——你的工具层、记忆层、规划层。这才是你的产品真正能拉开差距的地方。
